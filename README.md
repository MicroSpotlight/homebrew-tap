# MicroSpotlight Tap

## Install OpenHarness

```sh
brew install --cask microspotlight/tap/openharness
```

## How do I install other formulae?

`brew install microspotlight/tap/<formula>`

Or `brew tap microspotlight/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "microspotlight/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
